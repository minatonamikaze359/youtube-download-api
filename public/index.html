YouTube Downloader API

Welcome! This backend is hosted on Netlify and acts as a serverless API.

Available Endpoints:

1. Check Status

GET /api/

Returns server uptime and ping info.

2. Get Video Info

GET /api/info?url=YOUR_YOUTUBE_URL

Returns JSON containing the video title and thumbnail.

3. Download MP4 Video

GET /api/mp4?url=YOUR_YOUTUBE_URL

Streams and downloads the video file directly.

Running on Netlify Serverless Functions.
